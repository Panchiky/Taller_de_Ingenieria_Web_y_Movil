JavaScript: lo básico

1. Variables

En JavaScript guardamos datos en variables usando let o const.

let nombre = "Ana";
const edad = 20;

2. Funciones

Una función agrupa código que se puede reutilizar. Aquí abajo hay un ejemplo funcionando: escribe tu nombre en el formulario de arriba y presiona "Enviar".

function saludar() {
  let nombre = document.getElementById("nombre-input").value;
  document.getElementById("saludo-resultado").textContent = "¡Hola, " + nombre + "!";
}
